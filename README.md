# FinSmart Web Frontend

> Next.js 14+ PWA / Web Client for FinSmart – Smart Financial Literacy & Budget Planner for Public.

## Features
- **App Router & TypeScript**: Fast, scalable client architecture.
- **Multilingual Support (i18n)**: English (EN), Kannada (ಕನ್ನಡ - KN), and Hindi (हिन्दी - HI).
- **Household Ledger & Budget Tracker**: Real-time cashflow metrics, daily safe spending allowances, and threshold alerting (80% / 100%).
- **Savings Milestones**: Target date tracking with recommended monthly auto-allocation contributions.
- **Government Schemes Discovery**: Pure declarative rule DSL evaluations with explainability clauses and document checklists.
- **FinSmart AI Financial Mentor**: Grounded RAG assistant with automatic DPDP Act 2023 PII scrubbing and citations.
- **Precision Financial Calculators**: Loan EMI, SIP Wealth Builder, Emergency Fund Buffer, and Compound Interest.
- **Interactive Financial Literacy**: Vernacular lessons with instant-feedback quizzes and Cyber Crime Helpline (1930) alerts.
- **DPDP Act 2023 Privacy Center**: One-click DSAR data export and Right to be Forgotten account erasure.

## Running Locally

### With Docker:
The frontend runs automatically as part of FinSmart's 3-container topology on port `3000`.

### Standalone:
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).
